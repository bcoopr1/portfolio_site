CornerStone Designs

2026 · Full-Stack Engineer · Next.js · HTML · CSS · JavaScript

Clearwater Finance's core reporting tool had been running on a seven-year-old Rails monolith. It worked — barely. Generating a standard portfolio summary for a mid-size advisory firm took 40 seconds on average, and it would regularly time out for the larger clients. The UX was a symptom of the architecture: every change took weeks, because the system was too entangled to touch safely.

Over 14 months I led the rebuild from the ground up. The new backend is a Go API behind a PostgreSQL database with carefully tuned indexes and materialized views for the most common report shapes. The frontend is Next.js with server-side rendering for the initial load, then client-side transitions. Report generation now runs in under 800ms at p95, and the largest client's reports complete in under 2 seconds — a 95% reduction. The Rails system still runs in parallel for the two legacy integrations we haven't migrated yet, but its load is down 80%.

This project was also the first time I worked closely with a compliance team. Every data query had to pass through an audit-logging layer, and several report fields are masked for users without the right permissions. Building access control at the field level — without making every query hideously complex — was the most architecturally interesting problem I solved that year.
